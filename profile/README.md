# ParaProServices

ParaProServices, LLC is an Oklahoma company building **[Commutation.app](https://commutation.app)**.

Commutation.app is an AI-assisted web app that helps attorneys, and the incarcerated Oklahomans and families they serve, prepare commutation and clemency applications, including the reentry plan, grounded in public court and corrections records.

- Website: https://commutation.app
- Public repo: [commutation-app](https://github.com/ParaProServices/commutation-app)
- Contact: https://commutation.app/about#contact

Our product source code is private.

Commutation.app is not a law firm and does not provide legal advice.
